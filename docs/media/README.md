# docs/media/ — Visual assets

Images, mockups, screenshots, videos, audio, diagrams — anything binary and visual.

This folder currently holds the screenshots and demo video embedded in `README.md` (Command Center, Case Notes, Email Assistant, Call Script, Timezone, BAU Central, Configs, and `techsol-demo.webm`), generated by `generate-portfolio.py` (Playwright) against `mock-crm.html` — see `README.md` → Visual Portfolio Generation. It also holds `docs/verification/` evidence screenshots for specific fixes.

`CaseWizardDeck.gs` is the editable source for the company slide deck (project overview + user/TL guide): a standalone Apps Script that builds a full Google Slides presentation from scratch when pasted into Extensions > Apps Script of a blank 16:9 presentation. It expects 34 PNGs (23 app screenshots + 11 icons rendered from the project's own SVGs/colors) uploaded to a Drive folder — those PNGs aren't checked in here (regenerate them with the `export-css-logo-png` skill rather than hunting for a stale copy). Re-run the script any time the screenshots or module set change; it clears and rebuilds the deck idempotently.

## Conventions

- Organize by topic or feature (subfolders) as volume grows.
- Explicit names with date when relevant: `2026-05-11-onboarding-wireframe.png`.
- Prefer SVG or WebP for the web (smaller size).
- For diagrams: keep the editable source (`.excalidraw`, `.drawio`, `.fig`) next to the export.

## Avoid here

- Temporary debug screenshots → put them in `.gitignore` or delete after use.
- Heavy videos (>10 MB) → use Git LFS or external hosting. `techsol-demo.webm` predates this convention — check its size before adding more videos the same way.
